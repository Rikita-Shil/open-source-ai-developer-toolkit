# Architecture Overview

## Repository Structure

The Open Source AI Developer Toolkit is organised into modular developer skills. Each module is self-contained and includes documentation, examples, checklists, metadata, and sample inputs.

## Core Directories

- `skills/` – AI developer modules organised by category.
- `docs/` – Project documentation and contributor guides.
- `.github/` – GitHub Actions and community health files.
- `templates/` – Reusable templates for creating new modules.

## Design Principles

- Modular and easy to extend.
- Consistent structure across all modules.
- Beginner-friendly documentation.
- Production-oriented engineering practices.
- Open-source collaboration.
