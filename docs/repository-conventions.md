# Repository Conventions

This document defines the conventions used throughout the Open Source AI Developer Toolkit.

## Directory Structure

- `skills/` contains reusable AI developer modules.
- `docs/` contains project documentation.
- `templates/` contains reusable templates.
- `.github/` contains GitHub configuration files.

## Naming Conventions

- Use lowercase file names.
- Separate words with hyphens.
- Keep names descriptive and consistent.

## Commit Messages

Follow an imperative style:

- Add ...
- Improve ...
- Refactor ...
- Update ...
- Fix ...

Examples:

- Add API Reviewer module
- Improve project README
- Fix metadata validation

## Module Standard

Each module should include:

- README.md
- SKILL.md
- CHECKLIST.md
- examples.md
- sample-input.md
- metadata.json

## Goal

Maintain a clean, consistent, and scalable repository that is easy to navigate and contribute to.
