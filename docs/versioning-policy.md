# Versioning Policy

## Overview

The Open Source AI Developer Toolkit follows Semantic Versioning (SemVer).

Version format:

MAJOR.MINOR.PATCH

Example:

1.2.3

## Major Release

Increment the MAJOR version when introducing incompatible changes or significant architectural updates.

Example:

1.0.0 → 2.0.0

## Minor Release

Increment the MINOR version when adding new modules or features in a backwards-compatible way.

Example:

1.2.0 → 1.3.0

## Patch Release

Increment the PATCH version for documentation updates, bug fixes, or small improvements.

Example:

1.2.3 → 1.2.4

## Release Checklist

Before publishing a release:

- Update CHANGELOG.md
- Verify GitHub Actions pass
- Review documentation
- Validate module structure
- Tag the release in Git

## Current Development

The project is under active development, with new developer modules and documentation being added incrementally.
