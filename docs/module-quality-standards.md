# Module Quality Standards

This document defines the minimum quality requirements for every module in the Open Source AI Developer Toolkit.

## Required Files

Every module must contain:

- README.md
- SKILL.md
- CHECKLIST.md
- examples.md
- sample-input.md
- metadata.json

## Documentation

Each module should:

- Clearly describe its purpose.
- List supported technologies.
- Explain expected outputs.
- Include practical examples.

## Metadata

The metadata file should include:

- Name
- Category
- Version
- Author
- Difficulty
- Tags

## Review Checklist

Before merging a new module, confirm:

- All required files exist.
- Markdown formatting is valid.
- Examples are realistic.
- Metadata is complete.
- Naming follows repository conventions.

## Goal

Maintain a consistent, high-quality developer experience across all modules in the toolkit.
