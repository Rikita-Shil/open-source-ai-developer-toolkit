# Community

Thank you for your interest in the Open Source AI Developer Toolkit.

## How to Contribute

- Report bugs using GitHub Issues.
- Suggest new AI developer modules.
- Improve documentation.
- Submit pull requests with meaningful improvements.
- Follow the project's coding and documentation standards.

## Project Goals

- Build practical AI-powered developer tools.
- Encourage software engineering best practices.
- Maintain high-quality documentation.
- Foster an open and welcoming community.

Every contribution, no matter how small, helps improve the toolkit.
