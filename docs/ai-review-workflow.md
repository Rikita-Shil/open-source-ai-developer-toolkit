# AI Review Workflow

This document describes the recommended workflow when using the Open Source AI Developer Toolkit to review a software project.

## Recommended Order

1. Code Review Pro
2. Debug Detective
3. Security Auditor
4. Test Generator
5. API Reviewer
6. Performance Analyzer
7. GitHub Ready

## Why This Order?

Each module builds on the previous one:

- Identify code quality issues.
- Resolve defects.
- Review security concerns.
- Improve test coverage.
- Validate API design.
- Optimise performance.
- Confirm the project is ready for GitHub.

## Goal

Provide developers with a consistent, repeatable review process before publishing or deploying software.
