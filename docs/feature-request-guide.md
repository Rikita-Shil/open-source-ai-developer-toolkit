# Feature Request Guide

This guide explains how to propose new features or modules for the Open Source AI Developer Toolkit.

## Before Requesting a Feature

Before submitting a request:

- Check whether the feature already exists.
- Review the project roadmap.
- Search existing GitHub issues for similar suggestions.
- Consider how the feature fits the toolkit's goals.

## What to Include

A useful feature request should describe:

- The problem being solved.
- The proposed feature or module.
- Who would benefit from it.
- Example use cases.
- Any relevant technologies or frameworks.

## Module Requests

For a new developer module, also include:

- Proposed module name.
- Suggested category.
- Expected responsibilities.
- Example input and output.

## Goal

Feature requests should help the toolkit grow while keeping its modules practical, focused, and maintainable.
