# Module Deprecation Policy

This document explains how outdated modules are handled in the Open Source AI Developer Toolkit.

## When a Module May Be Deprecated

A module may be deprecated when:

- Its functionality is replaced by a newer module.
- The technology it supports is no longer maintained.
- The module no longer follows current project standards.
- Maintaining the module is no longer practical.

## Deprecation Process

Before removing a module:

1. Mark the module as deprecated.
2. Explain the reason for deprecation.
3. Recommend a replacement when available.
4. Update related documentation.
5. Record the change in the changelog.

## Goal

The deprecation process keeps the toolkit maintainable while giving users and contributors clear guidance when modules change.
