# Module Lifecycle

This document describes the lifecycle of a developer module in the Open Source AI Developer Toolkit.

## Stage 1 – Proposal

Define the purpose and scope of the module.

## Stage 2 – Structure

Create the module directory with the standard files:

- README.md
- SKILL.md
- CHECKLIST.md
- examples.md
- sample-input.md
- metadata.json

## Stage 3 – Documentation

Document the module's purpose, supported technologies, and expected outputs.

## Stage 4 – Validation

Review the module for consistency, formatting, and completeness.

## Stage 5 – Integration

Ensure the module follows the repository standards and can be used alongside other modules.

## Goal

Every module should be reusable, well documented, and easy for contributors to maintain.
