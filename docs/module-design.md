# AI Module Design Guide

This document defines the standard structure for every AI developer module in the toolkit.

## Required Files

Every module should include:

- README.md
- SKILL.md
- CHECKLIST.md
- examples.md
- sample-input.md
- metadata.json

## Design Principles

- Focus on solving one software engineering problem.
- Keep documentation concise and practical.
- Include realistic examples.
- Follow consistent formatting across modules.
- Use descriptive metadata.

## Review Checklist

Before submitting a new module:

- Documentation is complete.
- Examples are provided.
- Metadata is accurate.
- Markdown formatting is correct.
- File names follow the project standard.
