# Documentation Standards

To keep the project consistent, all documentation should follow these guidelines.

## Writing Style

- Use clear and concise language.
- Prefer practical examples over long explanations.
- Use descriptive headings.
- Keep formatting consistent across documents.

## Markdown

- Use proper heading hierarchy.
- Use fenced code blocks for commands and code.
- Use bullet points for lists where appropriate.

## File Naming

- Use lowercase file names.
- Separate words with hyphens.
- Keep names descriptive.

## Goal

Good documentation should help new contributors understand the project quickly and encourage high-quality contributions.
