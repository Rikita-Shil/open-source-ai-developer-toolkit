# Glossary

## AI Skill
A reusable AI workflow that performs a specific software engineering task.

## Module
A self-contained directory containing documentation, examples, metadata, and supporting files for an AI skill.

## Metadata
Information that describes a module, such as its name, category, version, author, and tags.

## Checklist
A list of best practices or review criteria used by a module.

## Sample Input
Example code or project content used to demonstrate how a module works.

## Examples
Illustrations of expected inputs, outputs, or review suggestions generated by a module.
